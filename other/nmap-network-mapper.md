### NMAP (Network Mapper)

### Hi Guys,

Nmap (Network Mapper) is a free and open-source tool used for network exploration, management, and security auditing. It is a command-line utility that runs on various operating systems, including Windows, Linux, and macOS.

**What is the usage of NMAP Tool?**

Nmap can perform a range of tasks, including:

**Host discovery**: Nmap can identify hosts on a network by using various methods such as ARP, ICMP, and TCP scanning.

**Port scanning**: Nmap can scan a range of ports on a target host to identify which ports are open or closed.

![](https://cdn-images-1.medium.com/max/800/1*Lre2vZXL6tMe-MDrg8BuUg.png)

**Service enumeration**: Nmap can identify the services running on open ports, including the service name, version, and operating system.

**Vulnerability detection**: Nmap can use various scripts and plugins to detect vulnerabilities in the scanned hosts and services.

**Network mapping**: Nmap can create a map of the network topology by identifying the devices and their relationships.

![](https://cdn-images-1.medium.com/max/800/1*zbihlpkTB50I7c0BEqFC_g.jpeg)

Nmap is widely used by security professionals, network administrators, and system administrators to identify potential security vulnerabilities and manage network resources. It can be used for various purposes such as network inventory, vulnerability assessment, penetration testing, and network troubleshooting.

To use Nmap, you need to specify the target IP address or hostname and the desired scan options. Nmap offers a wide range of scanning techniques and options, which can be customized based on your requirements.

### **Installation In Linux OS**

To install Nmap on Linux, you can use the package manager of your distribution. The following are the commands to install Nmap on some popular Linux distributions:

On Debian/Ubuntu:

```
sudo apt-get update  
sudo apt-get install nmap
```

On Red Hat/Cent OS:

```
sudo yum update  
sudo yum install nmap
```

On Fedora:

```
sudo dnf update  
sudo dnf install nmap
```

On Arch Linux:

```
sudo pacman -S nmap
```

Once the installation is complete, you can run the `nmap` command in the terminal to use the tool. To see the available options and usage examples, you can type `nmap -h` or `man nmap` to view the manual page.
